CRIS HANDWRITTEN — Version 1.0

A custom font traced from the two handwritten alphabet photographs.

INSTALL
Windows: Right-click the .ttf file and choose Install.
Mac: Double-click the .ttf file and choose Install in Font Book.
Android/iOS: Import using an app that supports custom fonts.

Includes uppercase, lowercase, digits, and selected punctuation.
The font is an initial tracing of photographs, so some letter spacing and glyphs may need refinement.
Use either TTF or OTF, not both, to avoid duplicate font entries.
